ANDROID APPLICATION

Bumpr

An Android application designed to simplify vehicle accident documentation and evidence collection through structured accident reporting, vehicle management, document storage and AI-assisted functionality.

Project Overview

Bumpr is a Java-based Android application which I developed to assist drivers with documenting vehicle accidents and organising important information following an incident.

The application aims to address the challenges drivers may experience when collecting accident evidence, recording information and preparing documentation required for any insurance or legal purposes.

Bumpr provides a structured approach to accident documentation through its dedicated features for managing vehicles, recording accident information, organizing supporting documents and preparing accident reports.

Key Features

User Registration & Login Vehicle Management Emergency Accident Mode Accident Evidence Collection Accident Party Management Insurance Document Vault AI-Assisted Documentation Accident Report Generation

System Architecture

Bumpr follows a client-server architecture comprising of an Android frontend, a PHP backend and a MySQL database.

The Android application provides the user interface and handles user interaction, while the PHP backend processes requests and manages communication with the database.

MySQL is used to store application data, including vehicle information, accident records and document details. HTTP requests are handled within the Android application using the Volley networking library.

AI Integration

Bumpr incorporates artificial intelligence through the integration of the Gemma 4 E2B language model using Ollama.

This integration demonstrates the use of a locally hosted AI model within an Android application, combining mobile development with AI-powered functionality.

The AI component forms part of Bumpr's accident documentation system, supporting the application's objective of improving how drivers collect and organize information following vehicle accidents.

Technologies Used

Java Android Studio XML PHP MySQL Volley REST APIs Ollama Gemma 4 E2B

Development Status

Bumpr is currently fully developed. The project focuses on integrating Android application functionality with backend services, database management and accident documentation workflows.

Further development includes the refining the user experience, improving the accident reporting process and investigating the implementation of AI-assisted features.
