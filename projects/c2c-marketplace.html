WEB APPLICATION

C2C Marketplace

A customer-to-customer marketplace application that allows users to browse, sell and purchase products through an online platform.

Project Overview

The C2C Marketplace is a web-based application designed to allow users to buy and sell products through an online marketplace. Users can browse available products and interact with the platform to manage their marketplace activities.

The application was developed using PHP and JavaScript for the application functionality, with MySQL used to store and manage user and product information. The project demonstrates web development, database management and user role functionality.

Technologies Used

PHP MySQL JavaScript HTML CSS
