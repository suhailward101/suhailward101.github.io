ANDROID APPLICATION

Campus Booking System

An Android application that allows students to browse campus venues, create and manage bookings, while administrators manage venues, users and booking information.

Project Overview

The Campus Booking System is a Java-based Android application designed to manage the reservation of campus venues. Students can register and log into the application, browse available venues and create and manage their bookings.

The application also includes administrative functionality. Administrators can manage venues, users and booking information through dedicated management features. This provides different functionality depending on the user's role within the system.

SQLite is used as the local database to store information relating to users, venues and bookings. The project demonstrates Android application development, database management and role-based functionality.

Key Features

User Registration User Login Venue Browsing Venue Booking Booking Management Admin Management

Technologies Used

Java Android Studio SQLite XML
