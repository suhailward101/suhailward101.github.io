ANDROID APPLICATION

TripBuddy

An Android travel planning application designed to help users organise trips, manage travel information and keep important trip details in one place.

Project Overview

TripBuddy is a native Android application developed to help users organise and manage their travel plans. The application provides users with a central place to store and manage important information relating to their trips.

The project was developed using Java and Android Studio, with SQLite used to store application data locally. The application demonstrates the use of Android activities, user interfaces, local data storage and application logic.

Technologies Used

Java Android Android Studio SQLite
